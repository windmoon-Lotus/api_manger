Token URL 配置

系统需要认证时，会调用你提供的 URL 获取 token。你的脚本/服务负责登录逻辑（包括 OTP、MFA 等），系统只负责拿结果。

典型用法：
• 本地跑一个脚本 python token_server.py 监听 localhost:9999，手动登录后返回 token
• 浏览器插件把最新 token 写到 localhost:9999/token
• OTP 工具暴露 GET /otp-token 接口
• 甚至 file:// 不行，但你可以用 python -m http.server serve 一个 JSON 文件

管理员可信代码认证

编写 get_auth(username, password) 函数，返回 {"headers": {...}, "cookies": {...}, "expires_in": 1800}。
可用模块：requests, hashlib, time, json, base64, hmac, uuid, re, math, datetime。 代码由管理员提供并视为可信插件；运行时使用独立子进程、超时和认证 Origin 白名单，但它不是敌对代码沙箱。
