# 原始数据是参考链，不是实际值

状态：设计原则。新增采集、存储或复用原始数据的代码时必须遵守。
日期：2026-09-16

## 1. 原则

原始请求/响应（抓包、执行留痕、流量样本）**只回答**：

> 谁、在什么时间、以什么身份、对哪个目标、做了什么、看到了什么。

原始数据**不回答**：

> 现在该用什么值。

后者必须由分级取值路径或一次新的读取给出。

## 2. 为什么

同一个 URL 返回什么，取决于三个会变的东西：

| 变化源 | 后果 |
| --- | --- |
| 账号轮换 | 同一 id 换账号后可能不存在、可能属于别人、可能权限不同 |
| 目标数据修改 | 对象被删/改后，旧响应里的 id 与字段已不是当前状态 |
| 认证主体变化 | 同一账号的不同 token 类型/受众，可见范围不同 |

因此一条历史响应里的值，**既不能证明现在存在，也不能证明现在可用**。
它能证明的只有"当时确实观察到过这个现象"——这正是它作为证据的价值。

## 3. 跨库拼接不可避免，所以要靠 provenance 而不是靠可复用性

原始数据与结构化结果分处不同存储（本地私有根 / MongoDB / 逐次运行的 JSONL）
是既有事实，强行合并反而会破坏各自的用途。接受拼接，但要求：

**每一次拼接都必须带 provenance**，即拼接结果要能回答"这条结论建立在谁的哪次观测上"。
缺少 provenance 的拼接结果一律不可用作结论。

## 4. 操作性规则

1. **不提供"取值"接口。** 原始数据仓储只暴露内容检索与血缘读取，
   不暴露"给我一个可用值"。需要值就走 `parameter_archive`
   （带 `value_quality`：`observed` / `sampled`）或实时读取。
2. **值有等级，等级必须传播。** `observed`（出现在响应里）与 `sampled`
   （只出现在请求样例里，可能是占位符）可信度不同，消费方必须能看到等级并自行决定，
   **不得静默取首个命中值**。
3. **append-only。** 新观测不覆盖旧观测；用 `superseded_by` 指向前者。
   一次与旧留痕矛盾的复测是**新证据**，不是对历史的修订。
4. **检索必须排除自身。** 跨运行检索默认排除调用方自己的 run，
   否则一条留痕会被用来确认产生它的那个结论。
   **该守卫失败要响**：排除参数非法时抛错，不得静默丢弃。
5. **截断必须标注。** 任何被截断的正文都以显式标记结尾，
   不得让下游以为拿到了完整内容。

## 5. 反例（本项目已发生）

- **盲取首值**：把参数池的归属判定降级成"字典首值穷举"后，
  攻方带着受害方的 id 拿到 200 与真正的越权访问**在证据上不可区分**。
  值可用不等于归属正确，而归属只能由确定性代码从参数与响应实体判定。
- **占位符当真实值**：归档里混着接口文档的请求样例，
  某必填参数取到文档占位符后请求返回 400，容易被误读成"接口不可用"。
- **一台当全站**：可达性只探了一台前端，把"未在实现"当成全平台结论，
  跨主机复核后有若干条被误判。

## 6. 与既有约定的关系

- `DATA_GOVERNANCE.md` 界定数据类与存储边界；本文件界定**原始数据的角色**。
- `docs/parameter_relation_validation.md` 说明取值与关系推断；
  本文件说明为什么这些推断不能以原始留痕直接替代。
- `docs/deterministic_vs_model_boundary.md` 说明谁有权下结论；
  本文件说明原始数据**不构成结论**，只是结论的依据。
- 落实现：`apiAnalysis/tool/trace_index.py`（只读检索，无取值接口，
  `search_prior_evidence` 强制排除自身 run）、
  `apiAnalysis/db/collection.py` 的 `request_trace`（append-only + `superseded_by`）。
