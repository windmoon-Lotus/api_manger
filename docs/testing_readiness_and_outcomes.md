# 执行条件与结果解释

2026-09-10

## 使用入口

1. 打开“测试计划”，选择项目，点击计划旁的“检查执行条件”。
   页面列出缺项和下一步动作。普通计划执行前服务端会再次检查；存在静态缺项时不会调用调度器。
2. 打开“项目执行中心”，选择一个运行，查看“本次运行产出了什么”。
   统计覆盖该运行的全部结果，不受下方分页影响。常见无法评估原因提供中文补齐建议。

## 解释边界

- 检查适用于测试计划页面的普通只读重放入口。专用授权矩阵、参数验证、写操作生命周期仍使用原有专用入口。
- 静态检查只读取项目、环境、认证方案状态和接口方法等元数据；不刷新凭据、不发送业务请求、不生成快照。
- 静态通过不证明认证可用、请求可构造或正常业务基线成功。普通重放缺少专用判断器时会明确提醒。
- 草稿、错误环境、认证不匹配、无效资产、写操作、执行器不兼容都不会在此入口进入调度。
- 结果统计按精确 verdict 分类，不把历史 outcome_class=pass 或未知结论升级为验证成功。
- 机器判断未发现、候选、无法评估、错误、待复核、其他分别统计；这些是记录数，不是独立接口覆盖率。
- 运行结束和机器结果都不等于漏洞确认或修复验证。没有结果时不显示虚假的成功率。
